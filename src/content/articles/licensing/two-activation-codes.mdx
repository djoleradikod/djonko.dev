<InShort>
Both codes come from the VCF Business Services console, and that is all they share. The **licensing activation code** connects a VCF Operations instance to the console in connected mode, so it can send usage and receive license files. Disconnected mode doesn't use one (<KB id={432201} />). The **depot activation code** (9.1) is issued when you register a **Software Depot ID** generated by the installer or the download tool. It replaces the 32-character download token that 9.0 used for binary downloads (<KB id={443647} />, <KB id={420374} />).
</InShort>

## Getting the depot code (9.1)

1. In the VCF Installer UI, or with the VCF Download Tool, generate a **Software Depot ID**.
2. Sign in to the console and register that ID. The console returns an **activation code**.
3. Enter the code in the installer or depot configuration.

Downloads then leave from the runtime node addresses, not only from SDDC Manager. If the code is accepted but downloads fail with 403, the firewall or proxy is the next suspect (<KB id={443166} />).

## Getting the licensing code

In VCF Operations, start registration in connected mode, sign in to the console, pick the Site ID, name the instance and generate the code. Paste it back into VCF Operations and activate. If it fails, generate a fresh code rather than retrying the old one (<KB id={428209} />).

<Callout type="field">
When asking a customer for "the activation code", say which one. In a change request, write "depot activation code for Software Depot ID ..." or "licensing activation code for VCF Operations instance ...". It saves a round trip with someone who has portal access and limited time.
</Callout>

## Pitfalls

- **Pasting the licensing code into the depot settings,** or the other way round. Both look similar and both fail with unhelpful errors.
- **Expecting the download token to keep working** after moving to 9.1. Plan the depot code as an upgrade prerequisite.
- **Lowercase names.** The name registered in the console for the depot should be lowercase. Mixed case has caused authentication failures.
