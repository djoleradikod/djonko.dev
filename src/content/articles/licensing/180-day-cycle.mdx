<InShort>
A 9.x license file is valid for a **rolling 180 days**, whatever the length of the subscription (<KB id={448518} />). Each usage report and license refresh moves the date out again. If 180 days pass without one, the license shows as **expired**, and a **90-day window** begins. After that, enforcement starts: management operations can be blocked, ESX hosts disconnect from vCenter, and new workloads cannot be created or powered on. **Running VMs are not stopped.** Recovery is always the same: get a refreshed license file into VCF Operations.
</InShort>

## What each banner means

| Message | Meaning |
|---|---|
| "The due date for submitting your usage report is on ..." | The normal 180-day reminder. Report usage and update. |
| "One or more licenses have expired and your service will be degraded on ..." | You are in the 90-day window. Act now (<KB id={438527} />). |
| "You have expired or expiring version 9+ licenses in your inventory" | Usually the 180-day window, sometimes a stale vSAN asset in 9.0 (<KB id={437580} />). |
| "Next Usage Report is required on ..." and the date won't move | The subscription itself may have ended, or a renewal needs **Change Capacity** (<KB id={449122} />). |
| Expiry alerts for keys you no longer use | Old keys on the **Pre-Version 9** tab. Remove them once that infrastructure is gone (<KB id={418555} />). |

## Hosts and evaluation

- A host added without enough capacity joins in **evaluation** and must be licensed within 90 days, or it disconnects. Its VMs keep running.
- A host whose own evaluation has already expired **cannot** take a subscription license. The documented fix is to reinstall it or open a case (<KB id={448638} />).
- If the evaluation runs out while VCF Operations or the License Server is down, hosts can disconnect and VMs can't power on (<KB id={443240} />). See [recovering an expired estate](/vcf/library/licensing/expired-estate-recovery/).

<Callout type="field">
Add "days until next licensing deadline, per VCF Operations instance" to the monthly report. In connected mode it should always read about 180. Any lower number is an early warning that the daily path is broken.
</Callout>

## Pitfalls

- **Reading the 180-day date as the contract end** and escalating a renewal that isn't needed. Check the console first.
- **Uploading usage after the subscription ended.** It does not extend past the subscription end date.
- **Ignoring evaluation hosts.** One forgotten host can be the only thing that disconnects.
